# Road to CCNA — office-network-lab

My hands-on journey preparing for the Cisco CCNA 200-301 exam, built in Cisco Packet Tracer.

Following [Jeremy's IT Lab CCNA course](https://www.youtube.com/@JeremysITLab) and the official CCNA 200-301 blueprint.

## Stages

1. Basic Device Config — hostnames, passwords, console security ✅
2. VLANs & Trunking — VLAN setup, trunk links between switches ✅
3. Subnetting (VLSM) — planning IP addresses 🔲
4. Static Routing 🔲
5. Inter-VLAN Routing 🔲
6. DHCP 🔲
7. ACLs 🔲
8. NAT 🔲
9. Port Security & SSH 🔲
10. STP / RSTP 🔲
11. EtherChannel 🔲
12. OSPF (single-area) 🔲
13. HSRP (First Hop Redundancy) 🔲
14. IPv6 Addressing & Routing 🔲
15. DHCP Snooping & Dynamic ARP Inspection 🔲
16. Wireless LAN Configuration 🔲
17. Network Automation (REST APIs, JSON) 🔲
18. Capstone — full office network with VLANs, routing, DHCP, ACLs, and NAT 🔲

## What's in each folder

Each stage has:
- The Packet Tracer file (.pkt)
- notes.txt — what I built, what I tested, and what I learned
- Screenshots (where applicable)

## Why this repo

This is both my personal study log and something others can follow if they're learning CCNA too. All labs, notes, and screenshots are my own work, done while following the course above.
